# Microsoft Enhances Fabric with Data Engineering Agent

**Date:** 2026-10-09  
**Category:** Data Engineering

## What Happened

Microsoft has introduced a preview of the Fabric data engineering agent, a new feature designed to automate and streamline complex data engineering tasks within the Microsoft Fabric platform. This agent is intended to assist developers and data engineers by planning, executing, validating, and refining workflows over extended periods, thereby reducing manual intervention and increasing efficiency.
