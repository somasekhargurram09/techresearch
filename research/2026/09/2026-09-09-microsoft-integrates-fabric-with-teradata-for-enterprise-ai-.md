# Microsoft Integrates Fabric with Teradata for Enterprise AI Workloads

**Date:** 2026-09-09
**Category:** Data Engineering

## What Happened

On September 2, 2026, Teradata Corporation announced a deep integration with Microsoft's OneLake, enabling enterprises to run Teradata's AI and analytics directly on OneLake data without the need for extraction, transformation, and loading (ETL) processes. This integration leverages open-source standards, allowing seamless data access and analysis within Microsoft's Fabric ecosystem. ## Why It Matters

This development is significant for data engineering as it streamlines the workflow for enterprise AI applications. By eliminating the need for data duplication or migration, organizations can achieve more efficient data governance and cost control. The direct integration also facilitates the placement of AI workloads across hybrid and multi-cloud environments, enhancing operational flexibility. ([simplywall.st](https://simplywall.st/stocks/us/software/nasdaq-msft/microsoft/news/microsoft-msft-opens-fabric-to-direct-enterprise-ai-workload/amp?utm_source=openai))

## Details

The integration allows Teradata's Autonomous Knowledge Platform to operate directly on data stored in Microsoft's OneLake, utilizing Apache Iceberg for efficient data management. This approach embeds Teradata within the Microsoft Fabric ecosystem, providing a unified analytics environment for joint customers. The collaboration aims to support mission-critical AI applications by offering a single, cohesive platform for data analysis and AI workload management.
