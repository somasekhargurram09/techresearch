# Microsoft Integrates Teradata's Enterprise AI with OneLake

**Date:** 2026-09-14
**Category:** Data Engineering

## What Happened

On September 2, 2026, Teradata announced a direct integration between its Autonomous Knowledge Platform and Microsoft's OneLake, enabling enterprise customers to run Teradata's high-performance enterprise AI directly on data stored in OneLake without the need for extract, transform, and load (ETL) processes, data duplication, or migration. ([nasdaq.com](https://www.nasdaq.com/press-release/teradata-brings-enterprise-ai-directly-microsoft-onelake-2026-09-02?utm_source=openai))

## Why It Matters

This integration simplifies the data pipeline by eliminating the need to move or replicate data between systems, thereby reducing latency and operational complexity. By allowing AI workloads to run directly on data where it resides, organizations can achieve faster insights and more efficient data management. Additionally, the use of open Apache Iceberg standards ensures compatibility and scalability across different platforms.
