# Microsoft Fabric Integrates with Teradata for Enhanced Enterprise AI Workloads

**Date:** 2026-09-22
**Category:** Data Engineering, AI

## What Happened

On September 2, 2026, Microsoft announced a deep integration between Microsoft Fabric and Teradata's enterprise AI capabilities. This collaboration enables enterprise AI workloads to run directly on Microsoft Fabric data without the need for duplication or migration. The integration is built on open-source standards, allowing customers to utilize Teradata's high-performance AI tools against Microsoft OneLake data in place. This development strengthens the Fabric and OneLake ecosystem for joint customers seeking mission-critical AI solutions within a unified analytics environment. ([simplywall.st](https://simplywall.st/stocks/us/software/nasdaq-msft/microsoft/news/microsoft-msft-opens-fabric-to-direct-enterprise-ai-workload/amp?utm_source=openai))

## Why It Matters

The integration between Microsoft Fabric and Teradata's enterprise AI capabilities marks a significant advancement in data engineering and AI. By enabling direct execution of AI workloads on Microsoft Fabric data, organizations can achieve more efficient data processing and analysis. This collaboration eliminates the need for data duplication or migration, reducing operational complexities and potential data inconsistencies. The use of open-source standards ensures flexibility and interoperability, allowing businesses to leverage existing tools and technologies seamlessly. For joint customers, this integration provides a unified platform for mission-critical AI applications, enhancing performance and scalability.

## Details

Microsoft Fabric is a comprehensive data engineering platform that facilitates the management, processing, and analysis of large-scale data. Teradata is a leading provider of enterprise AI solutions, offering high-performance analytics and data management tools. The integration between Microsoft Fabric and Teradata's enterprise AI capabilities allows organizations to run AI workloads directly on Microsoft Fabric data, eliminating the need for data duplication or migration. This approach leverages open-source standards, ensuring compatibility and flexibility for customers. The collaboration aims to provide a unified analytics environment for joint customers, enabling efficient and scalable AI applications.
